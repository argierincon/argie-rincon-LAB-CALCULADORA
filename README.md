Laboratorio de Calculadora en JavaScript - Evaluación

---

OBJETIVOS DE APRENDIZAJE

Al completar esta evaluación, serás capaz de:

- Diseñar y construir una calculadora básica que pueda sumar, restar, multiplicar y dividir dos números.
- Practicar la escritura de lógica condicional usando if, else if y else.
- Usar argumentos de línea de comandos para pasar valores a un script.

CÓMO EJECUTAR EL PROGRAMA

Puedes ejecutar el programa de la calculadora directamente usando Node.js.

Ejecutar directamente con Node.js

1. Abre la carpeta en Visual Studio Code.
2. Abre la terminal (Terminal > Nueva Terminal).
3. Ejecuta el script calculator.js usando Node.js, por ejemplo:

    node calculator.js 10 5 +

    Deberías ver el resultado impreso en la terminal:

    15

---

EJECUTAR LAS PRUEBAS

Ejecuta el script test.js usando Node.js, por ejemplo:

    node test.js

Deberías ver una salida indicando que todas las pruebas han pasado.
